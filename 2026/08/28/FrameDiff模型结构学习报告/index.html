1. 模型一句话概括

FrameDiff 是一个用于蛋白质 backbone 生成的 SE(3) 扩散模型。它不直接在所有原子坐标上做普通欧氏扩散，而是把每个残基表示成一个刚体 frame：

一个长度为 N 的蛋白 backbone 就是 N 个残基 frame 的序列：

扩散过程负责把真实 backbone frame 加噪成随机 frame；神经网络负责从带噪 frame 中预测去噪方向，也就是旋转 score 和平移 score；最后再用预测 frame 和 psi 扭转角重建 N、CA、C、O 等 backbone 原子坐标。

3. 数据表示：为什么是 frame 而不是直接坐标

3.1 残基 frame

每个残基 backbone 的核心原子是 N、CA、C。OpenFold/AlphaFold 风格的表示会用这三个点确定一个局部坐标系：

  • 原点常与 CA 位置相关；
  • N、CA、C 的几何关系确定局部 x/y/z 方向；
  • O 原子不能只靠 N、CA、C 完全确定，因此模型额外预测 psi 扭转角。

在代码里，训练数据通过 OpenFold transforms 生成 rigidgroups_0，随后取第 0 个 rigid group 作为 backbone frame：

to_tensor_7() 表示一个 rigid frame 被编码为 7 维，通常是 quaternion 4 维加 translation 3 维：

3.2 节点、边与 mask

一个蛋白被模型看成残基图：

  • node: 单个残基，形状大致为 [B, N, D_node]
  • edge: 残基对 (i, j)，形状大致为 [B, N, N, D_edge]
  • res_mask: 哪些位置是真实残基，哪些是 padding
  • fixed_mask: 哪些位置固定不扩散；无条件生成中通常全 0
  • diffuse_mask = (1 - fixed_mask) * res_mask: 哪些残基参与扩散和更新

16. 各模块的学习重点

如果你要系统学习这个模型，建议按下面顺序读：

  1. 先读 ScoreNetwork.forward：理解输入输出字段，不要一开始陷入 SO(3) 数学。
  2. 再读 Embedder.forward：看清 node/edge 特征如何构造。
  3. 读 IpaScore.forward：掌握主干 block 的执行顺序。
  4. 读 InvariantPointAttention.forward：这是最核心、最复杂的结构模块。
  5. 读 SE3Diffuser.forward_marginal 与 reverse：理解训练加噪和采样去噪。
  6. 最后读 loss_fn：把网络输出和训练目标对应起来。

17. 这个模型结构的优点

  • 用 SE(3) frame 表示 backbone，比直接生成原子坐标更贴合蛋白几何。
  • 旋转和平移分别在合适空间扩散：SO(3) 处理旋转，R^3 处理坐标。
  • IPA 能把序列表示、pair 表示和三维几何统一进 attention。
  • BackboneUpdate 每一层都更新 frame，使网络可以像 AlphaFold Structure Module 一样迭代修正结构。
  • self-conditioning 给模型提供上一轮预测的结构先验，通常能改善采样稳定性。

18. 需要注意的局限

  • 该模型主要生成 backbone，不直接生成完整 sidechain。
  • 默认训练数据过滤偏向单体蛋白，长度范围和结构分布受配置影响。
  • SO(3) 扩散依赖预计算 IGSO(3) 表格，理解和修改时要注意缓存。
  • 代码 README 也提到作者计划重构 score framework 以更贴近论文数学，因此当前实现有些地方更像工程实现而不是论文公式的直译。
  • 平移损失在当前默认配置下基本使用 x0 loss 分支，这一点和“纯 score matching”的直观说法略有差异，读代码时要特别留意。

19. 记忆版总结

FrameDiff 的网络可以记成四句话：

  1. 每个残基先被表示成一个 SE(3) 刚体 frame，而不是一堆自由原子坐标。
  2. 前向过程分别给 frame 的旋转和平移加噪，得到 rigids_t。
  3. 去噪网络用 IPA + sequence Transformer + frame update 反复更新残基表示和 frame。
  4. 输出的 frame、旋转/平移 score 和 psi 角共同恢复最终 backbone。

最核心的结构不是普通 Transformer，而是 IpaScore 中反复堆叠的 IPA block。IPA 让 attention 同时看见三件事：残基自身特征、残基对特征、当前三维空间位置关系。这正是它能用于蛋白 backbone 生成的关键。
