FrameDiff 公式推导整理：重排版

这份笔记重新整理 FrameDiff 的核心公式，重点放在推导链条本身，而不是逐字复刻论文。建议把它理解成四层：

  1. 蛋白 backbone 被表示成一组刚体 frame。
  2. 每个 frame 的旋转和平移分别做扩散。
  3. 为了全局 SE(3) 不变性，平移部分始终去质心。
  4. 网络预测去噪 frame，再由解析公式转成 score，用于训练和反向采样。

1. Backbone 的 frame 表示

第 n 个残基用一个 SE(3) 刚体变换表示：

\[ T_n = (R_n, x_n) \]

其中：

\[ R_n \in SO(3), \qquad x_n \in \mathbb{R}^3 \]

对任意局部原子坐标 a，frame 的作用是：

\[ T_n(a) = R_n a + x_n \]

长度为 N 的 backbone 是 N 个 frame 的集合：

\[ T = (T_1, T_2, \ldots, T_N) \in SE(3)^N \]

FrameDiff 使用理想化 backbone 局部坐标，以 alpha carbon 为原点：

\[ C_\alpha^\ast = (0,0,0) \]

\[ N^\ast = (-0.525,1.363,0), \quad C^\ast = (1.526,0,0), \quad O^\ast = (0.627,1.062,0) \]

N、C_alpha、C 可以直接由 frame 放置：

\[ N_n = R_n N^\ast + x_n \]

\[ C_{\alpha,n} = x_n \]

\[ C_n = R_n C^\ast + x_n \]

O 原子还需要一个 psi 扭转角。论文用二维单位向量表示 psi：

\[ \psi_n = (\psi_{n,1}, \psi_{n,2}), \qquad \psi_{n,1}^2 + \psi_{n,2}^2 = 1 \]

绕局部 x 轴旋转：

\[ R_x(\psi_n) = \begin{pmatrix} 1 & 0 & 0 \\ 0 & \psi_{n,1} & -\psi_{n,2} \\ 0 & \psi_{n,2} & \psi_{n,1} \end{pmatrix} \]

因此：

\[ O_n = R_n R_x(\psi_n) O^\ast + x_n \]

整体可以记作：

\[ [N_n, C_{\alpha,n}, C_n, O_n] = \operatorname{frame2atom}(T_n,\psi_n) \]

2. 从原子坐标构造 frame

训练数据给出真实 backbone 原子坐标，需要先从 N、C_alpha、C 构造残基 frame。

令：

\[ v_1 = C_n - C_{\alpha,n} \]

\[ v_2 = N_n - C_{\alpha,n} \]

用 Gram-Schmidt 得到局部坐标轴：

\[ e_1 = \frac{v_1}{\|v_1\|} \]

\[ u_2 = v_2 - e_1(e_1^\top v_2) \]

\[ e_2 = \frac{u_2}{\|u_2\|} \]

\[ e_3 = e_1 \times e_2 \]

于是：

\[ R_n = [e_1,e_2,e_3], \qquad x_n = C_{\alpha,n} \]

也就是：

\[ T_n = \operatorname{atom2frame}(N_n,C_{\alpha,n},C_n) \]

3. Riemannian score diffusion 的基础公式

在普通欧氏扩散里，数据逐渐变成高斯噪声；FrameDiff 的困难在于数据位于 SE(3) 流形上。论文先使用 Riemannian score-based diffusion 的通用形式。

设数据分布为 p0，参考分布为：

\[ p_{\mathrm{inv}}(x) \propto e^{-U(x)} \]

前向 SDE 是：

\[ dX_t = -\frac{1}{2}\nabla U(X_t)\,dt + dB_t \]

其中 B_t 是流形上的 Brownian motion。

反向生成过程需要当前边缘分布的 score：

\[ \nabla \log p_t(X_t) \]

时间反演公式为：

\[ d\bar X_t = \left( \frac{1}{2}\nabla U(\bar X_t) + \nabla \log p_{T-t}(\bar X_t) \right)dt + dB_t \]

实际中 score 不可直接得到，因此训练网络 s_theta：

\[ s_\theta(t,X_t) \approx \nabla \log p_t(X_t) \]

Denoising score matching 目标为：

\[ L_{\mathrm{DSM}} = \mathbb{E} \left[ \lambda_t \left\| \nabla \log p_{t|0}(X_t|X_0) - s_\theta(t,X_t) \right\|^2 \right] \]

关键点：训练时不需要真实边缘 score，只需要条件 score：

\[ \nabla \log p_{t|0}(X_t|X_0) \]

4. SE(3) 扩散为什么能拆成旋转和平移

FrameDiff 选择一个可拆分的 SE(3) 度量。对切向量 (a,u) 和 (a’,u’)：

\[ \langle (a,u),(a',u') \rangle_{SE(3)} = \langle a,a' \rangle_{SO(3)} + \langle u,u' \rangle_{\mathbb{R}^3} \]

其中：

\[ \langle A,B \rangle_{SO(3)} = \frac{1}{2}\operatorname{Tr}(AB^\top) \]

\[ \langle u,v \rangle_{\mathbb{R}^3} = u^\top v \]

这个度量使 SE(3) 上的 Brownian motion 分解为：

\[ B_{SE(3)}(t) = \left(B_{SO(3)}(t), B_{\mathbb{R}^3}(t)\right) \]

因此前向扩散可以拆成两部分：

\[ T_t = (R_t, X_t) \]

旋转部分是 SO(3) 上的 Brownian motion：

\[ R_t \in SO(3) \]

平移部分是欧氏空间中的 OU / VP-SDE：

\[ X_t \in \mathbb{R}^3 \]

条件 score 也对应拆分：

\[ \nabla_{T_t}\log p_{t|0}(T_t|T_0) = \left( \nabla_{R_t}\log p_{t|0}(R_t|R_0), \nabla_{X_t}\log p_{t|0}(X_t|X_0) \right) \]

5. 平移扩散：R3 部分

正文中的简化平移前向过程是 OU 过程：

\[ dX_t = -\frac{1}{2}X_t\,dt + dB_t \]

它的条件分布是：

\[ p_{t|0}(x_t|x_0) = \mathcal{N} \left( x_t; e^{-t/2}x_0, (1-e^{-t})I \right) \]

因此条件 score 是：

\[ \nabla_{x_t}\log p_{t|0}(x_t|x_0) = \frac{e^{-t/2}x_0-x_t}{1-e^{-t}} \]

实现中使用 beta schedule：

\[ \beta(t) = \beta_{\min} + t(\beta_{\max}-\beta_{\min}) \]

累计噪声为：

\[ G_x(t) = \int_0^t \beta(s)\,ds = t\beta_{\min} + \frac{1}{2}t^2(\beta_{\max}-\beta_{\min}) \]

实现版条件分布变成：

\[ p_{t|0}(x_t|x_0) = \mathcal{N} \left( x_t; e^{-G_x(t)/2}x_0, (1-e^{-G_x(t)})I \right) \]

对应 score：

\[ s_x^\ast(t,x_t,x_0) = \frac{e^{-G_x(t)/2}x_0-x_t}{1-e^{-G_x(t)}} \]

如果网络预测干净坐标 x0_hat，则使用：

\[ s_\theta^x(t,T_t)_n = \frac{e^{-G_x(t)/2}\hat x_{0,n}-x_{t,n}} {1-e^{-G_x(t)}} \]

6. 旋转扩散：SO(3) 与 IGSO(3)

旋转不能直接当作欧氏向量加高斯噪声，因为：

\[ R_t \in SO(3) \]

FrameDiff 使用 SO(3) 上的 Brownian motion。其条件密度是 IGSO(3)：

\[ p_{t|0}(R_t|R_0) = \operatorname{IGSO}_3(R_t;R_0,t) \]

它只依赖相对旋转角：

\[ \omega_t = \omega(R_0^\top R_t) \]

因此：

\[ \operatorname{IGSO}_3(R_t;R_0,t) = f(\omega_t,t) \]

其中：

\[ f(\omega,t) = \sum_{\ell=0}^{\infty} (2\ell+1) e^{-\ell(\ell+1)t/2} \frac{\sin((\ell+1/2)\omega)} {\sin(\omega/2)} \]

旋转条件 score 是：

\[ \nabla_{R_t}\log p_{t|0}(R_t|R_0) = R_t \frac{\log(R_0^\top R_t)}{\omega_t} \frac{\partial_\omega f(\omega_t,t)}{f(\omega_t,t)} \]

其中 log 是 SO(3) 矩阵对数。

实现中用 sigma schedule 控制旋转噪声：

\[ \sigma_r(t) = \log \left( t e^{\sigma_{\max}} + (1-t)e^{\sigma_{\min}} \right) \]

于是实现版旋转核写成：

\[ p_{t|0}(R_t|R_0) = \operatorname{IGSO}_3 \left( R_t;R_0,\sigma_r^2(t) \right) \]

7. 为什么必须中心化

蛋白整体平移不应改变分布，但在整个 R^(3N) 空间上不存在有限的平移不变概率分布。因此 FrameDiff 不在完整平移空间中建模，而是在去质心子空间中建模：

\[ \sum_{n=1}^{N} x_n = 0 \]

定义去质心投影：

\[ P = I_N - \frac{1}{N}\mathbf{1}\mathbf{1}^\top \]

三维坐标上实际使用：

\[ P_3 = P \otimes I_3 \]

中心化后的前向扩散：

\[ dT_t = \left( 0, -\frac{1}{2}P_3X_t \right)dt + \left( dB_{SO(3)^N}(t), P_3dB_{\mathbb{R}^{3N}}(t) \right) \]

直观理解：每一步加噪后，都把所有 C_alpha 坐标的质心移回原点。

这样模型最终学习的是整体旋转和平移不敏感的 backbone 分布。

8. FramePred：从去噪 frame 到 score

网络输入带噪 frame 和时间：

\[ (T_t,t) \]

输出预测的干净 frame 和 psi：

\[ (\hat T_0,\hat\psi) = \operatorname{FramePred}(T_t,t;\theta) \]

其中：

\[ \hat T_0 = (\hat R_0,\hat X_0) \]

FrameDiff 的 score 参数化不是让网络直接吐出 score，而是：

\[ \hat T_0 \quad \Longrightarrow \quad \nabla \log p_{t|0}(T_t|\hat T_0) \]

也就是把网络预测的干净结构代入解析条件 score。

平移 score：

\[ s_{\theta,n}^x = \frac{e^{-G_x(t)/2}\hat x_{0,n}-x_{t,n}} {1-e^{-G_x(t)}} \]

旋转 score：

\[ s_{\theta,n}^r = R_{t,n} \frac{\log(\hat R_{0,n}^\top R_{t,n})} {\omega(\hat R_{0,n}^\top R_{t,n})} \frac{\partial_\omega f(\omega,t)} {f(\omega,t)} \]

其中：

\[ \omega = \omega(\hat R_{0,n}^\top R_{t,n}) \]

9. 训练损失

总的 score matching 损失分为旋转和平移：

\[ L_{\mathrm{DSM}} = L_{\mathrm{DSM}}^r + L_{\mathrm{DSM}}^x \]

旋转 DSM：

\[ L_{\mathrm{DSM}}^r = \mathbb{E} \left[ \lambda_t^r \left\| \nabla_{R_t}\log p_{t|0}(R_t|R_0) -s_\theta^r(t,T_t) \right\|^2 \right] \]

平移 DSM 在合适权重下可化简为 x0 预测误差：

\[ L_{\mathrm{DSM}}^x = \frac{1}{N} \sum_{n=1}^{N} \|x_{0,n}-\hat x_{0,n}\|^2 \]

仅靠 DSM 会生成大体拓扑合理但局部几何较差的结构，因此论文加入 auxiliary loss。

令：

\[ \Omega = \{N, C_\alpha, C, O\} \]

backbone 原子坐标损失：

\[ L_{\mathrm{bb}} = \frac{1}{4N} \sum_{n=1}^{N} \sum_{a\in\Omega} \|a_{0,n}-\hat a_{0,n}\|^2 \]

局部 pairwise distance 损失：

\[ d_{ab}^{nm} = \|a_{0,n}-b_{0,m}\| \]

\[ \hat d_{ab}^{nm} = \|\hat a_{0,n}-\hat b_{0,m}\| \]

\[ L_{2D} = \frac{1}{Z} \sum_{n,m=1}^{N} \sum_{a,b\in\Omega} \mathbf{1}\{d_{ab}^{nm}<0.6\} \|d_{ab}^{nm}-\hat d_{ab}^{nm}\|^2 \]

这里 0.6 的单位是 nm，也就是 6 Angstrom。

最终损失：

\[ L = L_{\mathrm{DSM}} + w\mathbf{1}\{t<T_F/4\} \left( L_{\mathrm{bb}}+L_{2D} \right) \]

10. 反向采样

从参考分布开始：

\[ T_1 \sim p_{\mathrm{inv}}^N \]

也就是：

\[ R_1 \sim U(SO(3)), \qquad X_1 \sim \mathcal{N}(0,I) \]

并对 X1 去质心。

设步长为：

\[ \gamma = \frac{1-\epsilon}{N_{\mathrm{steps}}} \]

每一步先由网络预测：

\[ (\hat T_0,\hat\psi) = \operatorname{FramePred}(T_t,t;\theta) \]

再计算：

\[ (s_{\theta,n}^r,s_{\theta,n}^x) = \nabla_{T_{t,n}} \log p_{t|0}(T_{t,n}|\hat T_{0,n}) \]

平移更新：

\[ Z_n^x \sim \mathcal{N}(0,I_3) \]

\[ W_n^x = P_3 \left( \gamma \left( \frac{1}{2}X_{t,n} +s_{\theta,n}^x \right) +\zeta\sqrt{\gamma}Z_n^x \right) \]

旋转更新：

\[ Z_n^r \sim T_{R_{t,n}}\mathcal{N}(0,I) \]

\[ W_n^r = \gamma s_{\theta,n}^r +\zeta\sqrt{\gamma}Z_n^r \]

用指数映射回到 SE(3)：

\[ T_{t-\gamma,n} = \exp_{T_{t,n}} \left( W_n^r,W_n^x \right) \]

其中 zeta 是采样噪声缩放系数：

\[ 0 \leq \zeta \leq 1 \]

zeta 越小，采样越接近确定性反推；通常 designability 更好，但多样性可能下降。

11. 一句话总公式

FrameDiff 的整体推导可以浓缩成：

\[ \operatorname{atoms} \to T_0=(R_0,X_0) \to T_t=(R_t,X_t) \to \hat T_0=\operatorname{FramePred}(T_t,t) \to s_\theta=\nabla\log p_{t|0}(T_t|\hat T_0) \to \operatorname{reverseSDE} \to \operatorname{newBackbone} \]

最重要的结论：

  1. SE(3) 通过合适度量拆成 SO(3) 和 R3 两个扩散。
  2. 平移部分是 OU / VP-SDE，score 有高斯解析式。
  3. 旋转部分是 SO(3) Brownian motion，条件核是 IGSO(3)。
  4. 为了整体 SE(3) 不变性，所有平移坐标都要保持去质心。
  5. 网络预测的是干净 frame，真正用于扩散反推的是由条件核解析得到的 score。
